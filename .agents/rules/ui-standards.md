\# Metacog UI \& Architecture Standards



\## Tech Stack Requirements

\* Framework: Next.js 15 utilizing the App Router architecture.

\* Language: TypeScript (Strict mode enabled).

\* Styling: Tailwind CSS with fully semantic, clean utility classes.

\* Components: Fully modular component structures built inside `src/components/`.

\* Visualizations: Responsive charts using `Recharts` wrapped inside `ResponsiveContainer`.



\## Code \& Quality Behavior

\* Do not write hardcoded layouts; use responsive flexbox/grid wrappers.

\* Every interactive element must feature a transition property for smooth UX.

\* Always ensure component type safety interfaces are explicitly declared.

\* Prioritize clean, inspectable UI layout logic over overly nested components.
